======================
Versi: 0.2.0 "Jendela"

1. Apa itu NIDE
---------------
NIDE adalah singkatan dari "NIDE Isn't a Desktop" (akronim rekursif,
seperti GNU). Meskipun namanya begitu, secara teknis NIDE adalah
compositor Wayland kecil berbasis wlroots yang berperan sebagai
lingkungan desktop minimal. Anggap saja dia sebagai "desktop" yang
sangat minimal:

- Jendela mengambang (floating), bukan disusun tiling.
- Jendela tampil polos: tanpa title bar, border, atau tombol close.
- Semua keybinding diatur lewat file Lua.
- Config dimuat ulang otomatis saat file disimpan (hot reload).
- Hanya ada satu binary kecil dan satu file config.

NIDE BUKAN aplikasi yang bisa dijalankan di dalam KDE sebagai window
manager biasa. Saat dijalankan sebagai sesi, NIDE menggantikan desktop
KDE. Untuk mencoba di dalam KDE tanpa logout, jalankan secara "nested"
di dalam Xephyr (lihat bagian 4.3).


2. Istilah dasar
----------------
Compositor
    Program yang mengatur layar, jendela, keyboard, dan mouse. Di Linux
    modern, compositor sekaligus menjadi window manager.

Floating
    Jendela bisa diletakkan dan diubah ukurannya bebas, tidak otomatis
    disusun seperti grid.

Fokus
    Jendela yang sedang menerima input keyboard. Klik jendela untuk
    memfokuskannya.

Keybinding
    Kombinasi tombol yang menjalankan aksi, misalnya Super+W untuk
    membuka terminal.

Spawn
    Menjalankan program baru dari dalam compositor.

Nested
    Menjalankan NIDE di dalam jendela pada desktop yang sudah ada,
    biasanya memakai Xephyr. Berguna untuk uji coba.


3. Build dan install
--------------------
Kebutuhan di Arch Linux:

    sudo pacman -S --needed base-devel wlroots0.20 lua54

Build dari folder proyek:

    cd ~/Projects/nide
    make

Cek konfigurasi tanpa menjalankan compositor:

    ./nide --check -c config/config.lua

Install ke sistem:

    sudo make install PREFIX=/usr

Gunakan PREFIX=/usr supaya binary dan file sesi berada di lokasi yang
dipindai display manager:

    /usr/bin/nide
    /usr/share/wayland-sessions/nide.desktop
    /usr/share/nide/config.lua          (template, bukan config aktif)

Salin config ke folder pribadi:

    mkdir -p ~/.config/nide
    cp config/config.lua ~/.config/nide/config.lua

Uninstall:

    sudo make uninstall PREFIX=/usr

Catatan: kalau install tanpa PREFIX=/usr, file sesi akan masuk ke
/usr/local/share/wayland-sessions. Sebagian display manager tidak
memindai folder itu, jadi PREFIX=/usr lebih aman.


4. Menjalankan NIDE
-------------------
Ada beberapa cara menjalankan NIDE. Pilih sesuai kebutuhan.

4.1 Sebagai sesi penuh dari greeter (pemakaian normal)
------------------------------------------------------
Prasyarat: sudah menjalankan "sudo make install PREFIX=/usr" dan
menyalin config ke ~/.config/nide/config.lua.

1. Logout dari sesi desktop saat ini.
2. Di layar login (SDDM), buka menu sesi. Biasanya ada di pojok kiri
   bawah atau kanan bawah.
3. Pilih "NIDE", lalu login seperti biasa.

Setelah masuk, NIDE langsung menjadi desktop. Semua aplikasi yang
dijalankan akan menjadi klien Wayland milik NIDE.

Kalau NIDE tidak muncul di daftar sesi:

    ls -l /usr/share/wayland-sessions/nide.desktop
    which nide

Keduanya harus ada. Kalau file baru saja dipasang tetapi belum muncul,
restart SDDM (ini akan logout sesi yang sedang berjalan):

    sudo systemctl restart sddm

4.2 Dari TTY
------------
Cara ini berguna kalau tidak memakai display manager atau ingin uji
langsung di hardware.

1. Pindah ke TTY dengan Ctrl+Alt+F3 (F4, F5, dst. juga bisa).
2. Login dengan user biasa.
3. Jalankan:

    cd ~/Projects/nide
    ./nide -c ~/.config/nide/config.lua

Atau kalau sudah di-install:

    nide -c ~/.config/nide/config.lua

Keluar dari NIDE dengan Super+Shift+Q.

4.3 Nested di dalam KDE/X11 memakai Xephyr (untuk uji coba)
-----------------------------------------------------------
Cara paling aman untuk mencoba tanpa logout. Xephyr membuat layar X11
virtual; NIDE berjalan sebagai jendela di dalamnya.

Kalau Xephyr belum terpasang:

    sudo pacman -S xorg-server-xephyr

Lalu jalankan:

    cd ~/Projects/nide

    Xephyr :5 -screen 1280x800 &
    sleep 1

    DISPLAY=:5 WLR_BACKENDS=x11 WLR_RENDERER=pixman \
      WLR_RENDERER_ALLOW_SOFTWARE=1 ./nide -c config/config.lua

Keterangan:
- Jangan pakai :0, :1, atau :2. Di KDE, nomor itu dipakai XWayland.
- Kalau ":5 sudah aktif", ganti ke :6, :7, dst.
- Setelah jendela Xephyr muncul, KLIK dulu di dalamnya.
- Super+W, Super+C, dan Super+Shift+Q baru bekerja setelah jendela
  Xephyr mendapat fokus.

Kalau tombol Super tidak sampai ke NIDE, kemungkinan shortcut global
KDE menangkapnya lebih dulu (misalnya Super+W untuk Overview). Untuk
uji nested, sementara ubah binding ke alt+w di config, atau uji di
sesi penuh (greeter/TTY) yang tidak punya shortcut KDE.

Setelah selesai, keluar dari NIDE dengan Super+Shift+Q, lalu tutup
jendela Xephyr.

4.4 Langsung sebagai jendela XWayland
-------------------------------------
Kalau tidak ingin memakai Xephyr:

    cd ~/Projects/nide
    WLR_BACKENDS=x11 WLR_RENDERER=pixman \
      WLR_RENDERER_ALLOW_SOFTWARE=1 ./nide -c config/config.lua

NIDE akan muncul sebagai jendela 1024x768. Klik jendela itu sebelum
menekan keybinding. Sama seperti cara nested, shortcut global KDE bisa
merebut kombinasi Super.

Environment yang dipakai untuk uji nested:
- WLR_BACKENDS=x11          memaksa backend X11
- WLR_RENDERER=pixman       renderer software
- WLR_RENDERER_ALLOW_SOFTWARE=1  izinkan renderer software

Kalau layar hitam atau gagal render, pastikan dua variabel terakhir
dipakai.


5. Pemakaian sehari-hari
------------------------
Jendela baru
    Muncul di tengah monitor tempat kursor berada, lalu digeser
    bertahap 32 piksel agar tidak menumpuk persis.

Fokus
    Klik jendela untuk fokus. Jendela baru otomatis fokus. Klik area
    kosong untuk melepas fokus keyboard.

Pindah jendela
    Tahan Super, klik-kiri di mana saja pada jendela, lalu geser.
    Lepas tombol mouse untuk selesai.

Ubah ukuran
    Tahan Super, klik-kanan pada jendela, lalu geser. Ukuran berubah
    dari sudut kanan bawah. Lepas tombol mouse untuk selesai.

Tutup jendela
    Super+C. Ini mengirim permintaan close resmi ke aplikasi, bukan
    mematikan paksa. Aplikasi yang punya dialog "simpan file?" bisa
    menampilkan dialog itu.

Keluar dari NIDE
    Super+Shift+Q. Semua aplikasi akan kehilangan koneksi Wayland dan
    ikut tertutup. Simpan pekerjaan dulu.

Clipboard
    Copy/paste biasa didukung. Paste dengan klik tengah (primary
    selection) juga didukung.

Yang tidak ada:
    Tidak ada tombol close/minimize/maximize di jendela, tidak ada
    Alt+Tab, tidak ada bar/panel, dan tidak ada workspace. Fokus
    berpindah dengan klik atau saat jendela baru dibuka.


6. Konfigurasi
--------------
6.1 Lokasi file config
----------------------
Urutan pencarian config saat NIDE start:

1. Path dari opsi -c
2. Environment variable NIDE_CONFIG
3. $XDG_CONFIG_HOME/nide/config.lua
4. ~/.config/nide/config.lua
5. ./config.lua (folder tempat NIDE dijalankan)

Kalau memakai -c, file itu wajib ada. Kalau NIDE_CONFIG diisi, file itu
juga wajib ada. Untuk tiga lokasi berikutnya, NIDE memakai file pertama
yang bisa dibaca.

Untuk pemakaian normal, letakkan config di:

    ~/.config/nide/config.lua

File config/config.lua di folder proyek hanyalah contoh/template.
Mengubah file itu tidak otomatis mengubah sesi greeter, kecuali kamu
menjalankan NIDE dengan -c config/config.lua atau menyalinnya ke
~/.config/nide/config.lua.

Alur yang disarankan:

    # edit config pribadi
    nano ~/.config/nide/config.lua

    # cek tanpa menjalankan compositor
    cd ~/Projects/nide
    ./nide --check -c ~/.config/nide/config.lua

    # uji nested memakai config yang sama
    DISPLAY=:5 WLR_BACKENDS=x11 ... ./nide -c ~/.config/nide/config.lua

6.2 Config bawaan dan hal penting
---------------------------------
Kalau TIDAK ada file config yang ditemukan, NIDE memakai binding
bawaan:

    nide.bind("super+w", "spawn", "foot")
    nide.bind("super+c", "close")
    nide.bind("super+shift+q", "quit")

PENTING: config bawaan hanya dipakai kalau tidak ada file config sama
sekali. Kalau file config ditemukan, isinya dipakai apa adanya; binding
bawaan TIDAK ditambahkan otomatis. Jadi kalau file config hanya berisi
Super+W, maka Super+C dan Super+Shift+Q tidak ada.

Selalu sertakan minimal satu binding quit, misalnya:

    nide.bind("super+shift+q", "quit")

Tanpa itu, kamu bisa terjebak di dalam NIDE. Cara darurat keluar:
pindah ke TTY dengan Ctrl+Alt+F3, login, lalu:

    pkill -x nide

6.3 Bentuk dasar perintah
-------------------------
Format:

    nide.bind("kombinasi", "aksi", "argumen")

Contoh:

    nide.bind("super+w", "spawn", "foot")
    nide.bind("super+c", "close")
    nide.bind("super+shift+q", "quit")

Aturan:
- Tiga argumen untuk aksi spawn; dua argumen untuk close dan quit.
- Kombinasi dan nama aksi ditulis sebagai string (pakai tanda kutip).
- Bagian terakhir kombinasi adalah nama tombol. Bagian sebelumnya
  adalah modifier.
- Nama modifier dan nama tombol tidak peka huruf besar/kecil.
- Modifier harus cocok persis. Binding "super+w" tidak aktif kalau
  kamu menekan Super+Shift+W. Caps Lock dan Num Lock tidak mengganggu.
- Kalau ada dua binding dengan kombinasi sama, yang terakhir dipakai.
- Maksimal 64 binding.
- Kombinasi tanpa modifier secara teknis bisa, misalnya "F12", tetapi
  tombol itu akan selalu ditelan oleh compositor. Sebaiknya selalu
  pakai modifier untuk tombol biasa.

Lua dasar yang berguna:
- Komentar satu baris: -- tulis komentar di sini
- Variabel: local terminal = "foot"
- String: "foot" atau 'foot'
- Baris baru tidak perlu titik koma.

File config dijalankan sebagai kode Lua penuh dengan library standar.
Artinya config bisa menjalankan perintah dan mengakses file. Hanya
pakai config yang kamu tulis sendiri atau yang kamu percaya.

6.4 Modifier yang tersedia
--------------------------
    shift
    ctrl        (alias: control)
    alt         (alias: mod1)
    super       (alias: win, logo, mod4)

Bisa digabung dengan tanda plus, urutan bebas:

    nide.bind("super+shift+q", "quit")
    nide.bind("ctrl+alt+t", "spawn", "foot")
    nide.bind("super+ctrl+left", "spawn", "echo contoh")

"Super" adalah tombol Windows/Logo pada keyboard PC.

6.5 Nama tombol
---------------
Nama tombol mengikuti nama keysym XKB. Yang umum:

    Huruf        : a b c ... z
    Angka        : 0 1 2 ... 9
    Enter        : Return
    Spasi        : space
    Tab          : Tab
    Escape       : Escape
    Backspace    : BackSpace
    Delete       : Delete
    Panah        : Left Right Up Down
    Home/End     : Home End
    Page         : Page_Up Page_Down
    Fungsi       : F1 F2 ... F12
    Tanda        : minus equal comma period slash backslash
                   semicolon apostrophe grave bracketleft bracketright
    Multimedia   : XF86AudioRaiseVolume, XF86AudioLowerVolume,
                   XF86AudioMute, XF86AudioPlay, XF86MonBrightnessUp

Kalau tidak yakin nama sebuah tombol, pakai program "wev" (Wayland
event viewer):

    sudo pacman -S wev
    wev

Tekan tombol yang ingin dipakai, lalu cari tulisan "keysym" di output.
Nama itulah yang ditulis di config.

6.6 Aksi yang tersedia
----------------------
spawn
    Menjalankan perintah shell. Argumen ketiga wajib diisi.
    Contoh: nide.bind("super+w", "spawn", "foot")
    Perintah dijalankan lewat /bin/sh -c, jadi argumen, pipe, dan
    variabel shell boleh dipakai.
    Contoh: nide.bind("super+b", "spawn", "firefox --new-window")

close
    Meminta aplikasi yang sedang fokus menutup jendelanya.
    Tidak butuh argumen. Kalau tidak ada jendela fokus, tidak terjadi
    apa-apa.

quit
    Keluar dari compositor. Tidak butuh argumen.
    Semua aplikasi Wayland akan terputus dan tertutup. Simpan dulu
    pekerjaanmu.

Tidak ada aksi lain. Keybinding untuk memindahkan jendela, tiling,
workspace, atau maximize belum tersedia; gerakan jendela memakai mouse
(Super+klik).

6.7 Contoh config lengkap
-------------------------
Contoh harian:

    -- Terminal favorit. Ganti sesuai yang terpasang.
    local terminal = "foot"

    -- Launcher aplikasi (opsional, harus terpasang).
    local launcher = "fuzzel"

    -- Buka terminal.
    nide.bind("super+w", "spawn", terminal)

    -- Buka launcher.
    nide.bind("super+d", "spawn", launcher)

    -- Tutup jendela yang fokus.
    nide.bind("super+c", "close")

    -- Keluar dari compositor.
    nide.bind("super+shift+q", "quit")

    -- Cetak pesan ke log saat config dimuat (opsional).
    nide.log("config NIDE dimuat, versi " .. nide.version)

Contoh beberapa aplikasi:

    local terminal = "foot"

    nide.bind("super+w", "spawn", terminal)
    nide.bind("super+b", "spawn", "firefox")
    nide.bind("super+f", "spawn", "nautilus")
    nide.bind("super+t", "spawn", terminal .. " --title=terminal-baru")
    nide.bind("super+c", "close")
    nide.bind("super+shift+q", "quit")

Contoh tombol multimedia (butuh wpctl/PipeWire):

    nide.bind("XF86AudioRaiseVolume", "spawn",
        "wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+")
    nide.bind("XF86AudioLowerVolume", "spawn",
        "wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-")
    nide.bind("XF86AudioMute", "spawn",
        "wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle")

Kalau sebuah perintah gagal, NIDE tidak menampilkan notifikasi.
Jalankan perintahnya dulu di terminal untuk memastikan program ada.
Contoh:

    command -v foot
    command -v fuzzel

6.8 Debug config
----------------
nide.log(...) mencetak pesan ke log NIDE. Bisa menerima beberapa nilai
yang dipisahkan koma:

    nide.log("terminal =", terminal, "versi =", nide.version)

nide.version berisi string versi NIDE.

Saat dijalankan dari terminal, log langsung terlihat. Tambahkan opsi
-d untuk log wlroots yang lebih detail:

    ./nide -d -c ~/.config/nide/config.lua

Saat dijalankan dari greeter/SDDM, log biasanya ada di:

    ~/.local/share/sddm/wayland-session.log

dan:

    journalctl -b -u sddm

6.9 Cek config dan hot reload
-----------------------------
Cek config kapan saja tanpa mengganggu sesi:

    cd ~/Projects/nide
    ./nide --check -c ~/.config/nide/config.lua

Contoh output yang benar:

    Config : /home/user/.config/nide/config.lua
    Keybinding (3):
      super+w              -> spawn foot
      super+c              -> close
      super+shift+q        -> quit

Kalau ada error Lua, NIDE menampilkan nama file dan pesan errornya,
termasuk nomor baris. Perbaiki lalu cek lagi.

Hot reload:

NIDE memantau file config yang sedang dipakai. Setelah file disimpan,
binding baru langsung dipakai tanpa restart. Jendela yang sedang
terbuka tidak terpengaruh.

Kalau ada file config, saat start log menampilkan path yang dipantau:

    hot reload aktif untuk /home/user/.config/nide/config.lua

Saat berhasil dimuat ulang:

    config dimuat ulang: /home/user/.config/nide/config.lua (4 keybinding)

Aturan dan perilaku:

- Hanya file config aktif yang dipantau. Kalau NIDE dijalankan dengan
  -c config/config.lua, file itulah yang dipantau, bukan
  ~/.config/nide/config.lua.
- Kalau file dihapus atau dipindahkan, config lama tetap dipakai.
- Kalau file disimpan tetapi berisi error Lua, reload dibatalkan dan
  config lama tetap dipakai. Errornya muncul di log; perbaiki lalu
  simpan lagi.
- Config dengan 0 keybinding ditolak. Tetap disarankan selalu punya
  binding quit agar tidak terkunci.
- Kalau saat start tidak ada file config sama sekali (mode bawaan),
  tidak ada file yang dipantau. Buat config lalu restart sekali.
- Editor yang menyimpan dengan rename (vim, nano, dan sejenisnya)
  didukung.

Melihat log hot reload:

- Dari terminal: log langsung terlihat.
- Dari sesi SDDM: cari "hot reload" atau "dimuat ulang" di
  ~/.local/share/sddm/wayland-session.log.

Kalau reload tidak terdeteksi, cek path yang diedit dan path yang
tertulis di log. Sebagai fallback, restart NIDE dengan Super+Shift+Q
lalu jalankan lagi.

6.10 Kalau config rusak dan tidak bisa masuk
--------------------------------------------
Kalau config memiliki error, NIDE menolak start dan login dari greeter
bisa langsung kembali ke layar login. Perbaiki dari TTY:

1. Ctrl+Alt+F3, login.
2. Cek error:

    nide --check -c ~/.config/nide/config.lua

3. Edit config:

    nano ~/.config/nide/config.lua

4. Kalau perlu, pulihkan contoh bawaan:

    mkdir -p ~/.config/nide
    cp ~/Projects/nide/config/config.lua ~/.config/nide/config.lua

5. Cek lagi, lalu kembali ke greeter dengan Ctrl+Alt+F1 atau F2.


7. Perilaku dan tampilan jendela
--------------------------------
Tanpa dekorasi
    NIDE meminta aplikasi memakai server-side decoration, tetapi NIDE
    sendiri tidak menggambar title bar, border, atau tombol. Aplikasi
    juga tidak menggambar dekorasi sendiri. Hasilnya jendela benar-
    benar polos.

Konsekuensi:
- Tidak ada tombol close di jendela. Pakai Super+C.
- Tidak ada area title bar untuk drag. Pakai Super+klik-kiri.
- Tidak ada handle resize. Pakai Super+klik-kanan (sudut kanan bawah).

Penempatan
    Jendela baru diletakkan di tengah output tempat kursor berada.
    Setiap jendela baru digeser 32 piksel dari jendela sebelumnya
    (cascade), berulang setiap 8 jendela. Posisi dijaga minimal 8
    piksel dari tepi layar.

Fokus
    Jendela baru langsung fokus. Klik jendela lain untuk berpindah.
    Klik area kosong melepas fokus keyboard.

Maximize/fullscreen
    Permintaan maximize dan fullscreen dari aplikasi tidak diterapkan.
    Jendela tetap floating.

Multi-monitor
    Output dideteksi otomatis dan disusun oleh wlroots. Belum ada
    pengaturan posisi monitor manual. Jendela baru muncul di monitor
    tempat kursor berada.

Clipboard
    Clipboard dan primary selection didukung selama aplikasi sumber
    masih hidup. Tidak ada clipboard manager.

Skala/HiDPI
    Belum ada pengaturan skala atau fractional scaling. Tampilan
    mengikuti output apa adanya.


8. Opsi command line dan environment
------------------------------------
Opsi command line:

    -c, --config PATH   memakai file config tertentu
    -C, --check         cek config lalu keluar
    -d, --debug         log debug wlroots (lebih banyak output)
    -v, --version       tampilkan versi
    -h, --help          tampilkan bantuan

Contoh:

    ./nide --check -c config/config.lua
    ./nide -d -c ~/.config/nide/config.lua
    ./nide --version

--version menampilkan versi NIDE, misalnya:

    nide 0.2.0

Environment yang relevan:

    NIDE_CONFIG
        Path config, dipakai kalau -c tidak diberikan.

    XDG_CONFIG_HOME
        Basis folder config. Kalau diisi, NIDE mencari
        $XDG_CONFIG_HOME/nide/config.lua lebih dulu.

    WLR_BACKENDS=x11
        Untuk uji nested di X11/Xephyr.

    WLR_RENDERER=pixman
        Renderer software untuk uji nested.

    WLR_RENDERER_ALLOW_SOFTWARE=1
        Mengizinkan renderer software.

NIDE juga mengatur environment untuk aplikasi yang di-spawn:
    WAYLAND_DISPLAY      socket Wayland milik NIDE
    XDG_CURRENT_DESKTOP  diisi "NIDE"

Jangan mengatur WAYLAND_DISPLAY secara manual saat menjalankan NIDE;
NIDE membuat socket sendiri dan meneruskannya ke aplikasi anak.


9. Batasan
----------
Ini proyek minimal, bukan pengganti desktop lengkap. Yang belum ada:

- XWayland. Aplikasi X11 tidak bisa dijalankan.
- layer-shell. Bar/panel seperti Waybar dan notifikasi berbasis
  layer-shell belum didukung.
- Maximize, fullscreen, minimize, animasi, shadow, dan dekorasi.
- Alt+Tab / window switcher dan workspace.
- Tiling, snap, atau pengaturan layout.
- Pengaturan posisi/scale multi-monitor secara manual.
- Input method (IME) untuk bahasa dengan komposisi.
- Idle management, screen lock, dan DPMS otomatis.
- Touch, tablet, dan gesture.
- Konfigurasi warna, gap, border, atau tema kursor.

Kalau butuh fitur-fitur itu, NIDE bisa dijadikan fondasi untuk
dikembangkan, tetapi saat ini belum tersedia.


10. Troubleshooting
-------------------
"./nide: No such file or directory"
    Kamu belum berada di folder proyek. Jalankan:

        cd ~/Projects/nide
        ./nide -c config/config.lua

"Server is already active for display :5"
    Nomor display sudah dipakai. Pilih nomor lain, misalnya :6 atau
    :7. Di KDE, :0, :1, dan :2 dipakai XWayland, jadi jangan dipakai.

"gagal membuat backend" atau "failed to open DRM device"
    Backend DRM tidak bisa dipakai. Penyebab umum:
    - Sudah ada sesi grafis lain yang aktif.
    - Tidak punya izin seat/logind.
    - Mencoba DRM di dalam sesi Wayland tanpa backend X11.
    Untuk uji di desktop, pakai WLR_BACKENDS=x11 dan Xephyr seperti
    pada bagian 4.3.

Super+W tidak membuka terminal di Xephyr
    - Pastikan jendela Xephyr sudah diklik/fokus.
    - Pastikan binding ada di config yang dipakai (cek --check).
    - Pastikan foot terpasang: command -v foot.
    - Shortcut global KDE mungkin menangkap Super+W. Coba ubah binding
      sementara ke alt+w, atau uji di sesi penuh.

Terminal tidak muncul, tidak ada pesan error
    Perintah spawn berjalan lewat shell; kalau program tidak ada,
    errornya hanya masuk log NIDE. Cek log dan jalankan perintahnya
    manual di terminal.

"gagal memuat config ..."
    Ada error Lua atau kesalahan nama aksi/kombinasi. Jalankan:

        ./nide --check -c ~/.config/nide/config.lua

    Pesan error menunjukkan baris yang bermasalah.

Tidak ada binding close/quit
    Config yang ditemukan menggantikan binding bawaan. Tambahkan:

        nide.bind("super+c", "close")
        nide.bind("super+shift+q", "quit")

Terjebak di NIDE tanpa binding quit
    Pindah ke TTY dengan Ctrl+Alt+F3, login, lalu:

        pkill -x nide

    Kalau sedang nested, tutup jendela Xephyr atau hentikan proses
    NIDE dari terminal lain.

Login dari greeter langsung kembali ke layar login
    Periksa:

        ~/.local/share/sddm/wayland-session.log
        journalctl -b -u sddm
        nide --check -c ~/.config/nide/config.lua
        which nide

    Pastikan binary ada di /usr/bin/nide dan config valid.

Aplikasi X11 tidak mau jalan
    Normal. NIDE tidak mengaktifkan XWayland. Gunakan aplikasi yang
    mendukung Wayland. Untuk aplikasi yang punya dua backend, paksa
    Wayland, misalnya:

        GDK_BACKEND=wayland aplikasi
        QT_QPA_PLATFORM=wayland aplikasi

Jendela tidak punya title bar atau tombol close
    Itu memang desain NIDE. Gunakan Super+C untuk menutup dan
    Super+klik-kiri untuk memindahkan.

Config sudah diubah tetapi tidak berpengaruh
    Config aktif dimuat ulang otomatis, jadi pastikan:
    - File benar-benar disimpan ke disk, bukan hanya di buffer editor.
    - File yang diedit sama dengan path di log "hot reload aktif".
    - Tidak ada error config di log; kalau error, config lama tetap
      dipakai.
    - Kalau sesi dimulai tanpa file config (mode bawaan), buat config
      lalu restart sekali.
    Kalau masih tidak terdeteksi, restart dengan Super+Shift+Q lalu
    jalankan lagi, atau logout/login dari greeter.

Layar hitam di Xephyr
    Pastikan memakai:

        WLR_BACKENDS=x11
        WLR_RENDERER=pixman
        WLR_RENDERER_ALLOW_SOFTWARE=1

    Lalu klik jendela Xephyr. Cek juga log NIDE di terminal.


11. Referensi cepat
-------------------
Build:

    cd ~/Projects/nide
    make

Cek config:

    ./nide --check -c ~/.config/nide/config.lua

Setelah config disimpan, NIDE memuat ulang binding secara otomatis.
Tidak perlu restart; jendela yang sedang terbuka tetap berjalan.

Install untuk greeter:

    sudo make install PREFIX=/usr
    mkdir -p ~/.config/nide
    cp config/config.lua ~/.config/nide/config.lua

Uji nested:

    Xephyr :5 -screen 1280x800 &
    DISPLAY=:5 WLR_BACKENDS=x11 WLR_RENDERER=pixman \
      WLR_RENDERER_ALLOW_SOFTWARE=1 ./nide -c config/config.lua

Binding bawaan (hanya kalau tidak ada file config):

    Super+W          buka foot
    Super+C          tutup jendela fokus
    Super+Shift+Q    keluar dari NIDE

Mouse:

    Super+klik-kiri   pindah jendela
    Super+klik-kanan  ubah ukuran dari sudut kanan bawah

Contoh config minimal:

    local terminal = "foot"

    nide.bind("super+w", "spawn", terminal)
    nide.bind("super+c", "close")
    nide.bind("super+shift+q", "quit")

Semoga membantu. Mulai dari config minimal, cek dengan --check, uji
nested, lalu install ke greeter kalau sudah nyaman.
